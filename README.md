# Claude Projects

Projects built with Claude. Each one lives in its own folder with its own README and setup steps.

**Site:** [brax10jns.github.io/Claude-Projects](https://brax10jns.github.io/Claude-Projects/)

| Project | What it does |
| --- | --- |
| [Resume Gauntlet](resume-gauntlet/) | Screens a resume like an applicant tracking system, then runs it past an interviewer, a rival applicant, a field expert and an executive, and walks you through fixing every issue they flag. |
| [Essay Gauntlet](essay-gauntlet/) | Screens an essay against its assignment, then runs it past a classmate, a teacher or professor, a seasoned writer and a renowned expert on the topic, and walks you through fixing every issue they flag. |
